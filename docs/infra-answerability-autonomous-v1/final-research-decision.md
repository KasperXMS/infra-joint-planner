# Final research decision

**No-Go for H1/H2 progression in this run.** Eight preregistered task diagnostics produced zero original-evaluator successes, so a legitimate task-answering path was not recovered. No new frozen H1 or H2 cells were started. This is the scientifically required stop, not a claim that all possible evidence renderings or models fail.

The original `UNKNOWN` pattern is narrowed, not uniquely explained. Completed historical model inputs contained both full MultiHop support articles and were not silently truncated; the model still abstained. MMQA had a confirmed one-of-two support-document retrieval miss. G1 MultiHop lost article-level provenance and used a different source scope. Synthetic protocol probes worked, while grounded/reasoning task diagnostics either abstained, answered incorrectly or exhausted their output budget. The earlier HTTP 413 was a separate bounded-read mismatch, already corrected for the historical replacement pair. JSON presentation, distracting evidence and model capability remain unresolved relative contributors.

Technical defects were identified and addressed to the limit the gate permits: a tested, source-local provenance/index contract is prepared as a new condition, and actual Worker bounded-read behavior is regression-tested. It was **not** deployed or falsely counted as a successful workflow. Neither G0 nor G1 passed the same original task; historical H1 is unsupported in the tested setting and the general H1 claim remains inconclusive. H2 was not started, so there is no measured Infrastructure Information Value. H3 and an Infra-aware Workflow Adapter remain **No-Go** until a separately frozen, independently scored quality-acceptable pair exists.

Resource accounting for this branch: 8/8 diagnostic task model calls, 0/16 H1/H2 executions, 3/20 short protocol probes; no paid cloud API. Task diagnostic HTTP wall summed 33.08 seconds with 88,028 prompt and 1,800 completion tokens. GPU monetary cost and attributable service time are unknown. Raw model/evaluator evidence remains on the experiment machine; [redacted outcomes and manifests](model-answerability.md) are committed here.
