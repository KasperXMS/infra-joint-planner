# Correctness repairs and limits

Technical commit `5a0812a` adds a source-local, gold-blind provenance contract and deterministic regressions. `build_provenanced_index` reads only originals on the owning source that belong to question-named publisher groups, checks each blob against its frozen manifest SHA256, and carries the full article body plus original ID, source collection, selecting operator, representation, producer and consumer. `validate_selected_records` fails closed on missing/shard-only IDs, duplicated IDs, source/hash/role mismatches, altered article fields and altered original blobs. The derived index is bounded to 8 MiB. An offline run against the real archives validated four task/producer indexes and their BM25-selected records; see [provenance-check-public.json](provenance-check-public.json). The code is a **new-condition utility**, not a deployed Worker change. No H1 cell used it, and historical G1 traces are untouched.

The historical 65,536-byte Source-B read cap caused an observed HTTP 413 on a 91,164-byte selected artifact. The prior study changed only its own Worker configuration to a 262,144-byte bounded cap before the replacement pair. This branch does not modify the generic Worker default or restart any Worker. Regression tests exercise the actual Worker API: 91,164 bytes returns 200, 262,145 bytes returns typed `artifact_too_large` HTTP 413, and the original artifact SHA256 stays unchanged. `require_readable_output` applies the same bound to a proposed selected-read path. Existing transfer-receipt logic was not changed.

Focused validation: 17 tests across the new provenance cases and existing Worker API tests pass; Ruff check and format pass; strict Pyright on the provenance utility reports zero errors. The standalone offline audit scripts are linted but are not a deployed runtime. No source data, evaluator, benchmark, original result or shared serving configuration was modified. Further live integration/requalification is gated on a legitimate answerability path and must be separately labeled; it is not represented as completed here.
