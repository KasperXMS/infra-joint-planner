## Why a separate proof is needed

Raw root HTTP responses prove actual `estimate_*` query attempts, including the
final turn absent from later SDK history. The existing source-aware collector
already reports these calls, actual request interface exposure and unknown replies.
An actual returned card is separate evidence. Merely counting it does not establish
that its exact structured result entered a later Manager context or was used by
an identical later action. The C-specific quote visibility helper does not prove
B visibility: B returns `card_id`, rather than a mandatory `quote_id` response.

`large_scale_optional_card_adoption_audit_v1.py` joins a returned card to its exact
created root proposal, checks advisory/consequence equality, and scans actual root
SDK function outputs for exact response/call-ID equality. It joins an actual action
only via the explicit matched-card receipt, exact semantic fingerprint, prepared
action and physical/logical outcome receipts. Semantic payload excludes only the
SDK action ID; inputs, arguments, output declarations, prompt and requirements
remain exact. It is not a new action-normalization rule or execution path.

The legacy quote observation identifies the proposal, while `cost_card.matched`
identifies the later execution. Those different IDs are expected, not a missing
handoff or runtime defect. Physical completion metadata is emitted after optional
match/quote-observation events in the actual frozen gateway. Do not impose a false
event-order assumption that confuses receipt emission with inference timing.

Exposure is counted before matched action preparation, or through trace end for
an unexecuted card. Exposure alone does not imply an execution. A failed matched
execution is not successful adoption; absent outcomes stay unknown or fail the
claimed linkage. Duplicate, foreign, forged, reordered or inconsistent receipts
fail closed. No cost imputation, quality inference, provider query denominator,
causal optimization claim or system winner is generated by this helper.

Only IDs, counts, linkage flags and hashes leave it. Prompt/argument/task text,
artifact bodies, arbitrary messages, consequence values and physical identity
are not exported. This is evidence for later complete-block adoption auditing,
not private semantic primary-cause review, automatic pruning or PhaseII permission.
