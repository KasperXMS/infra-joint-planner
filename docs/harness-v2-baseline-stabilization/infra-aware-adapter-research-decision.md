# Infra-aware Adapter research decision

**Decision: No-Go for a full Infra-aware Workflow Adapter now.** The frozen H1 matrix has 21/24 method-pair L2 workflow differences but no repeatable two-trial quality-preserving cost improvement. Blind scores 3/12; Aware 2/12; Ledger 1/12. Protocol failures censor 12 Verifier paths, and H2 never exposes a real pending suffix. These facts make a large adapter's quality or cost effect uninterpretable at present. The prior Stage 3 No-Go remains in force.

The next narrowly testable research question is: *Can an SDK-native Planner explicitly propose a bounded, dependency-valid future fragment while retaining a useful open-ended trajectory, and can a new observation trigger a legitimate PATCH of only its pending suffix?* The scripted prototype proves the versioned state transitions are representable; it does not prove a live Planner will create them. A follow-on feasibility study should use distinct v2.1 condition IDs, fixed task/evaluator, explicit baseline protocol, and a predeclared measure of actual pending suffixes and valid PATCH opportunities. It should count rejected fragments and no-op/KEEP cases, preserve original task quality, and price added Planner/Verifier calls. No adapter selector or broad benchmark run is authorized or started here.

Before such a study, the independent Verifier boundary needs a separately measured reliability baseline using strict raw-schema and semantic validation with bounded typed recovery. The deterministic terminal mismatch should be corrected independently. Both changes may alter trajectories; comparisons must use new namespaces rather than overwrite the historical 36 cells. A genuine adapter opportunity would require repeated quality-preserving changes to retrieval/reduction/model input flow or transfer under different infrastructure conditions, beyond same-condition sampling variation. Video-MME's one favorable Aware pair and MultiHop's retrieval-count differences are candidates for diagnosis, not positive proof.

This is a research sequencing decision, not a claim of statistical significance from three anchors. It answers the central question conservatively: existing cost guidance changes workflows and often spends less, but the available traces do not establish reproducible quality-preserving infrastructure-aware savings; a bounded pending-plan interface is the minimum missing bridge for testing logical adaptation.
