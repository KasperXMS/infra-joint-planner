# Decision after H1/H2 feasibility

| Gate or hypothesis | Decision | Basis |
|---|---|---|
| P1 source/Controller isolation | **Go** | Separate A4/A5 source residency, mount-isolated Controller, denied direct paths, authorized receipted reads and hash-verified transfer; see `p1-isolation-closure.md`. |
| H1 logical workflow opportunity | **Unsupported in this pilot** | G0 and G1 differ in information acquisition/selection, but no task had two native-successful outcomes. A technical 413 was retained and its preregistered replacement also failed quality. |
| H2 infrastructure information value | **Inconclusive / not run** | No quality-feasible pair; no Hslow task observations or valid retrospective oracle. |
| H3 infrastructure-aware Planner | **Do not begin** | H1/H2 provide no quality-constrained payoff target for an Adapter. |
| Infra-aware Logical Adapter | **No-Go remains** | No evidence yet that infrastructure-conditioned logical decisions improve successful execution. |

Further workload evaluation is warranted only if the next separately scoped study first establishes native task success under legitimate original evidence and improves record-level provenance for source-selected outputs. The repeated `UNKNOWN` responses despite annotated MultiHop articles being selected make model/prompt/evidence interpretation a practical confounder. The Worker read cap was a separate execution contract miss; the study-only repair was recorded before replacement, and all initial data remain unchanged. Another confounder is G0's question-named publisher scope versus G1's whole-shard retrieval; a future matched candidate scope would isolate selection placement more cleanly. These observations are diagnostic priorities, not authorization to tune this frozen pilot or to start H3.

The user-requested same-weight vLLM migration was assessed separately. Both resident weights are Q4_K_M GGUF, and Qwen3-VL GGUF support is not yet qualified for the installed vLLM/plugin path. By user direction, both dual-4090 model services remain on Ollama; this study used the existing 27B endpoint throughout. Jetson feasibility and workstation serving evidence are documented in their respective notes.
