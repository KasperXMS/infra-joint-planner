# P1 isolation closure

**P1 Go for the bounded mount-isolated Controller runtime.** The Controller is a Python process inside the committed `bwrap` launcher, with only `/usr`, `/lib`, `/lib64`, `/study` (public inputs), `/out`, a private `/tmp`, `/proc` and `/dev` mounted. It shares networking for receipted Worker RPC but has no host home, source store, raw benchmark copy, evaluator labels, SSH credential or source read token mounted. Its actual UID is 1000 in a user/PID/IPC/UTS namespace. The independent evaluator remains outside this boundary. Future H1/H2 trial scripts must use exactly this launcher or repeat P1.

`source-a` is a study-owned A4 Worker on `192.168.0.104:63204`, with persistent local ext4 artifact store. `source-b` was newly staged on the distinct A5 physical Worker `192.168.0.105:63217`, also on its local ext4 store. This is a versioned copy of the parent source-b package plus correction delta; historical workstation artifacts were preserved. Source-b has 248 originals and A4 has 438 originals. Both serve the unmodified v0.1 Worker code from separately named roots. Source-a's Hfast proxy on A4 port `63206` paces protected GET responses at nominal 100 Mbps and 5 ms additional RTT; Hslow port `63205` is separately study-owned. Host `tc` was never changed.

The [redacted P1 receipt](p1-isolation-receipt-public.json) records seven denied direct path opens, including both source roots, the workstation's older benchmark copy and private evaluator file, and `/proc/1/root` bypass. No forbidden host mounts were present. Unauthenticated GET on both source Workers returned 403. An unknown source version failed with a persistent failed action receipt. Authorized remote reads on both Workers succeeded with action receipts. A 10,348-byte A4 artifact was pulled by A5 through the Hfast proxy; destination SHA256 matched its manifest hash, measured transfer was 194.785 ms, and the study-created replica was removed. The original 686 source placements were verified by actual Worker state. The initial receipt was followed by a distinct `p1-002` verification run after adding the explicit unknown-version failure test; no historical v0.1 probe was overwritten.

The isolation claim is scoped to the mounted Controller process. Running the Planner directly under the unrestricted workstation account would reopen the historical P1 blocker. This runtime is not a general hostile-network sandbox: Workers expose administrative APIs to authorized research clients, and the Controller shares host networking. Trial code must enforce the frozen source URL allowlist and log all source RPC bytes. Future experiments must also keep private labels out of `/study` and score only in the independent host evaluator.

After the initial H1 G1 task hit the study Source-B Worker's 65,536-byte `read_artifact` ceiling, only the study Source-B config was changed to 262,144 bytes and that Worker restarted before the preregistered replacement pair. The initial four cells retain their original config and results. The replacement manifest records the revised code hash and read ceiling; the Worker code, source originals, evaluator and Controller mount boundary were unchanged.
