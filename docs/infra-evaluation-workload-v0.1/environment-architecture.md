# Minimal environment architecture

The environment reuses the existing Worker RPC, `OperatorRegistry`, `FileArtifactStore`, HTTP artifact pull, receipts and runtime executor. No MCP, A2A, new Planner, Scheduler rewrite, or generalized database was added. Two study-owned Worker instances were launched on previously unused ports: AGX Orin A4 `63104` and workstation `63117`. Each read only its own persistent artifact directory. The code and data were deployed under unique `infra-evaluation-workload-v0.1` roots; historical services and raw traces were untouched.

`artifact_read_token_env` is an optional Worker setting. When configured, direct `/artifact/{id}` GET requires a token known to source Workers, and semantic operations require an `action_id`, so they leave an `ActionReceipt`. `HttpArtifactFetcher` forwards that token only to allowlisted source hosts. Existing deployments without the setting keep their prior behavior. The token is stored only on experiment machines and is absent from Git/configs. This is a narrow P1 source-read guard, not a comprehensive authorization redesign: operators intentionally allow receipted source evidence reads, artifact PUT/DELETE remain administrative APIs, and the Controller host still has local source-b filesystem access.

The tested path was `source-a FileArtifactStore → source-a Worker GET → LAN → source-b Worker pull → source-b FileArtifactStore`; the HTTP body and destination SHA256/byte count were checked. For the network profiles, two additional study-owned A4 proxy ports paced the same GET response before crossing the LAN. The hosts' `tc` rules were never changed. [`service-cleanup-public.json`](service-cleanup-public.json) records all four study processes stopped and ports closed. Persistent base source artifacts remain available for reproducibility.

The physical mount check found A4 data on `/mnt/ssd` local ext4 (`/dev/nvme0n1p1`) and source-b data on workstation local ext4 (`/dev/nvme0n1p2`); these are distinct host filesystems. This proves separate storage for source-a and source-b, but does not prove that the Controller process lacks other historical copies on its own workstation. That unresolved privilege/mount boundary is the P1 isolation blocker.
