This study asks whether native reusable skills compensate for Qwen3.5-4B/9B planning limitations on real agent tasks. The configuration below was frozen before formal development/evaluation cells. Infrastructure smoke outcomes are separate from development and held-out results. Historical synthetic results are excluded from every official success-rate denominator.

The attached research brief is the governing specification. Work began on 2026-10-13 at approximately 11:48 HKT. AutoDL must remain running after experiments, failures, or budget exhaustion. Only this study's model, runner, tunnel, and containers may be stopped. No whole-instance lifecycle automation is used.

## Model and harness freeze gate

Intended models: official Qwen/Qwen3.5-4B and Qwen/Qwen3.5-9B, BF16, context 32,768, temperature 0, thinking disabled. Exact official repository commits and every downloaded file hash are recorded in `models.lock.json`. ModelScope downloads are accepted only for weight files whose SHA256 equals the official Hugging Face LFS SHA256. Other model files come from pinned official Hugging Face revisions.

Deployment amendment: the preferred vLLM 0.20.2 environment could not be provisioned promptly because large dependency downloads repeatedly stalled. Its partial wheel cache and failure receipts are retained; no vLLM benchmark requests were collected. Use the validated official Transformers 5.19.0 serving implementation with the existing PyTorch 2.8.0+cu128 environment, BF16, SDPA, no compilation or continuous batching, seed 42 and serial tasks. Both models use this same backend. All 26 model files (28,672,142,686 bytes) match pinned hashes. This fallback is authorized by the brief; costs/latency describe this deployment and cannot be presented as optimized vLLM performance.

The common API contract disables thinking, uses greedy decoding, reserves 4,096 output tokens, and rejects input+output exceeding 32,768 tokens. Generation stops at both original model EOS and tokenizer chat EOS, including `<|im_end|>`; otherwise this version's default generation config continues into fabricated turns. Original model bytes are unchanged. Transformers' native Qwen parser emits XML scalar arguments as strings. After generation, the relay applies the unchanged `_convert_param_value` method from the official vLLM v0.20.2 Qwen3Coder parser (full upstream source SHA256 `223b45bebad925d173427d5935ea933c0d91e2d123392ad6a66f7428ae64cabc`). Native and decoded responses and conversions are retained privately. No guided/schema-constrained decoding is enabled, and tool names, missing/extra parameters, prompts and tool schemas are not repaired. An integer/array API roundtrip passed with actual usage accounting.

Use BenchFlow's supported OpenHands ACP adapter, CLI commit `3ca17446c5d9c1e35e054803478a3501ec251ecf`, SDK/tools 1.22.1 (the adapter's official pins), unchanged tools and permissions, and native skill paths. ## Runs and failure policy

Stage A: 2 models × 8 development tasks × S0/S1 = 32 runs. Stage B may develop at most one mechanism supported by actual development traces and a comparison to prior work. No intervention is currently proposed. Stage C: 2 models × 16 held-out tasks × S0/S1 = 64 runs; add all 32 S2 runs only if a method is frozen before held-out outcomes are inspected. No optional 27B or transfer runs are planned before the main study is complete.

One initial trial per cell; no answer-based automatic retries, verify-retry loop, best-of selection, or failure-only reruns. Use single-shot rollout, task concurrency 1, and original task agent/verifier budgets consistently across treatments. Group by model and counterbalance S0/S1 ordering by task index. After each cell, wait for instrumented pending/running generation counts to reach zero, retaining any post-timeout requests and tokens in that cell's cost. Infrastructure faults stop affected batches; log revisions, preserve old outcomes, and apply any correction equally to affected treatments. Task difficulty or poor scores never justify changing conditions or skipping long tasks.

An unattended model-transition preflight was corrected after two 4B development cells had finished. Transformers serve returned HTTP 500 for `GET /v1/models`; chat completions and `/study/status` were healthy. The continuation watcher alone was replaced with one that checks service readiness and makes an excluded 9B identity/usage API probe. The 4B runner, frozen source/config, and existing scores were not changed or rerun. `transition-check-amendment.json` records the watcher PIDs and reason.

Before launching agent batches, freeze one complete machine-readable run configuration and request capture policy. Confirm tool calls, skill loading, artifacts, context limit, official verifier, and input/output isolation. Keep oracle/verifier and private credentials inaccessible to the solver. ## Analysis and inference limits

Primary outcome: original official task resolution reward, with exact numerator, denominator, missing-cell count, and infrastructure exclusions. Missing runs are missing, never fabricated passes/fails. Compare each model on paired tasks: S1 minus S0, rescue (0→1), regression (1→0), and per-domain/difficulty descriptive summaries. Compare 4B/9B treatment effects descriptively; one trial and 16 held-out tasks do not establish general scaling laws, statistical significance, or repeatability.

Secondary outcomes: workflow completion (separately defined from official reward), skill available/discovered/read/applied/executed, tool-call errors, planning turns, repeated failed operations, recovery, tokens, model latency, task E2E, setup/build time, and rental. File access alone is evidence of reading, not correct use. Failure categories must cite actual trace spans and distinguish knowledge, discovery, tool grounding, sequencing/state, recovery, and termination/artifact errors. Categories are provisional until development evidence exists.

RQ1–RQ8 require actual matched model runs and are presently unanswered. RQ2 repeatability requires predeclared complete paired repeats beyond the initial trial. RQ9 novelty is not established by reproducing a positive skill lift. Without a validated new mechanism, report an honest reproduction/diagnostic study.
