# Cost accounting protocol

The cost unit is one complete official task attempt: task image/setup, OpenHands install/start, all main-model and same-model condenser requests, tool calls, verifier, and any generation still running when a task timeout fires. Task start and model-idle drain times are stored in each `cell.json`. The separate build, agent and verifier durations come from the original BenchFlow `result.json`; summing those may omit orchestration gaps, so elapsed cell time is the primary wall-clock measure.

The AutoDL rate supplied in the brief is ¥7.35 per hour. Attribute an *incremental rental equivalent* to each serial cell as `7.35 × (quiescent_epoch − started_epoch) / 3600`. This is an allocation, not an additional fee. Also report rental for the complete study period, including model download/provisioning, idle time, model switches, development analysis, and final cleanup. The study started around 2026-10-13 11:48 HKT according to the protocol; this approximate anchor gives an estimated all-in rental with corresponding time uncertainty. Use exact process timestamps where available and never claim access to the provider's billing ledger. The instance continues billing after the experiment because the user requires it to remain online; report the ending observation time rather than implying rental stopped.

Two token counts are retained for reconciliation. `result.json` gives OpenHands' provider-reported prompt/completion tokens, including condenser calls. The authenticated bridge independently stores each actual HTTP response's usage and per-request latency. Use the bridge total for measured model service consumption; count missing/error responses separately. The AutoDL service writes token counts and generation time for requests that continue after a cancelled client call. Because formal tasks run serially and the runner waits for idle before moving on, those late generations can be associated with the active cell by their start and drain timestamps. Avoid double counting them when a response already supplies usage.

Final cost aggregation requires the complete backend reconciliation for each included stage. The report includes backend generation count and summed generation seconds for the same official cell windows, and rejects any backend/API token mismatch. Generation seconds are model service work time; they exclude idle, model loading, container setup, transfer, and verifier time, which remain represented by wall-clock and component timing fields. A transport disconnect can still have a counted generation when response capture completed before the write to the client failed.

No API per-token bill exists for these self-hosted weights. Tokens, inference latency, GPU memory and wall-clock rental are distinct quantities. WSL CPU/RAM, local disk usage and build time are measurable, but local electricity, hardware depreciation, internet transfer charges and human labor are not priced from the available evidence. Present the rental-equivalent and token/work measures together; do not label their sum as the complete economic cost. If no task passes in a condition, cost per pass is undefined and must be stated that way.

Excluded infrastructure attempts remain outside official success-rate and paired-cell denominators, but they consumed real time and sometimes model generations. The estimated all-in rental period includes them automatically. Report their attempt counts, elapsed time and observed tokens separately so the cell-only rental and token totals are not misread as the full research workload. In particular, the held-out context-overflow ACP attempt used 86 successful model responses before its two HTTP 400 rejections; its unscored work must not be silently omitted from resource accounting or added as a failed task score.
